# webadmin-ku-design

## Description
Proposes the initial Knowledge Unit (KU) structure for a website and allows the administrator to accept, modify, or extend the design. Use this skill when the admin wants to set up curated knowledge storage for a site. Call this skill when the admin asks about setting up knowledge units, AKU, or curated findings for a site, or wants to design the KU structure before storing operational insights.

## Help
Input: natural admin request about KU design for a specific site.

## Session Type
loop

## Instructions
Propose the standard KU design for the target website:
- site-positioning
- target-profile-strategy
- visitor-question-patterns
- lead-quality-analysis
- conversion-and-engagement-analysis
- privacy-consent-and-retention-decisions
- website-improvement-decisions

Allow the administrator to accept, modify, or extend this design. Create approved KUs through webadmin-ku-store.

## Allowed-Skills
- webadmin-ku-store
