# webadmin-ku-design

## Description
Proposes the initial Knowledge Unit structure for a website and allows the administrator to accept, modify, or extend the design.

## Help
Input: natural admin request about KU design for the active site-id.

## Session Type
loop

## Instructions
Propose the standard KU design for the active website:
- site-positioning
- target-profile-strategy
- visitor-question-patterns
- lead-quality-analysis
- conversion-and-engagement-analysis
- privacy-consent-and-retention-decisions
- website-improvement-decisions

Allow the administrator to accept, modify, or extend this design. Create approved KUs through webadmin-ku-store.

## Allowed-Skills
- webadmin-ku-store
