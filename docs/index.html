WebAdmin Agent Documentation

WebAdmin is a set of domain skills invoked through Achilles Copilot for administrative operations on WebAssist data. Every operation is scoped to a selected site-id.

Overview

WebAdmin is not a separate application. It is a skill set located in the webAssist agent workspace, invoked through Achilles Copilot in WebChat. WebAdmin skills provide domain operations: configuration, review, archive, reporting, and AKU management.

Data Structure

All WebAdmin operational data is stored under .ploinky/agents/webassist/data/sites/<site-id>/:

FolderPurpose
sessions/Session history files ({sessionId}-history.md)
leads/Lead files ({sessionId}-lead.md)
profiles/Target visitor profile templates
info/Website information files
config/Owner contact (owner.md) and policy (policy.md)
visits/Append-only events log (events.md)

.aku/Agentic Knowledge Units memory

Skills

webadmin-flow (Orchestrator)

Entry-point orchestrator. Interprets administrative requests, maintains the selected site-id, and delegates to authorized WebAdmin skills.

webadmin-context (Code Skill)

Loads metadata for the selected site-id: profile names, owner info, policy, lead IDs, session IDs.

webadmin-archive (Code Skill)

Archives sessions and leads by moving them to archive/sessions/ and archive/leads/. Requires explicit confirmation before execution.

webadmin-site-config (Code Skill)

Creates or updates website configuration: owner contact routes, visitor notice, consent policy, and retention rules.

webadmin-ownerInfo (Code Skill)

Creates, reads, updates, removes, and lists owner contact info.

webadmin-profiles (Code Skill)

Creates, updates, lists, removes, and reviews target visitor profiles and their mandatory conditions.

webadmin-sessions (Code Skill)

Lists and reads visitor sessions, inspects conversation histories and profile summaries.

webadmin-leads (Code Skill)

Lists and reads leads, reviews matching rationales, changes lead statuses, and archives selected leads.

webadmin-statistics (Code Skill)

Produces daily, weekly, and monthly summaries of visits, chats, origin distributions, matches, leads, and administrative outcomes.

webadmin-ku-design (Orchestrator)

Proposes the initial Knowledge Unit structure for a website. Administrator may accept, modify, or extend.

webadmin-ku-store (Code Skill)

Creates, updates, forks, archives, or discards site-scoped Knowledge Units through the AKU library.

webadmin-ku-consolidate (Orchestrator)

Reviews operational records selected by the administrator and produces consolidated findings for storage as KUs.

webadmin-ku-search (Code Skill)

Executes AKU keyword search and BM25F ranking, returns a compact ContextPack.

Orchestration

WebAdmin uses the webadmin-flow orchestrator, which processes each admin request by selecting exactly one skill, executing it, and formatting the result in the same language as the request. No manual skill selection is needed.

AKU Integration

Each website has its own AKU memory root under data/sites/<site-id>/.aku/. AKU stores curated knowledge derived from administrative work. Knowledge Units include: site-positioning, target-profile-strategy, visitor-question-patterns, lead-quality-analysis, conversion-and-engagement-analysis, privacy-consent-and-retention-decisions, and website-improvement-decisions.
